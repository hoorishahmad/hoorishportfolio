01 — object_detection_AR.unity

// Final Year Project · Computer Vision · Edge Deployment

Real-Time Object Recognition in AR

github.com/hoorishahmad · Unity · Python · ONNX · Unity Sentis · C#

ARDetect · live detection on Android · YOLOv8n · Unity AR Foundation

Problem & Objective

Run object detection live on the device camera inside an AR scene and augment recognized objects on the fly — entirely offline, no inference server. Target: a usable real-time experience on a mid-range Android phone.

Architecture & Pipeline

Train in PyTorch → export to ONNX → load & run in-engine with Unity Sentis at runtime. Benchmarked four detector backbones to find the accuracy/latency sweet spot for a constrained device.

  • Trading accuracy against latency across four architectures for a real-time, memory-limited target.
  • Reconciling ONNX export quirks so models load and run correctly inside Sentis.
  • Keeping detection stable as the AR camera pose and lighting shift frame to frame.
02 — ironveil_depths.js

// HCI · LLM Systems · Interactive Narrative

Ironveil Depths — LLM-Powered AI Game Master

github.com/hoorishahmad/ironveil-depths · JavaScript · HTML/CSS · OpenRouter API

Problem & Objective

Build a browser text-RPG where an LLM plays the Game Master — maintaining narrative coherence, in-character voice, and live game-state simultaneously. A direct HCI question: can an LLM sustain believable, stateful interaction over many turns?

Architecture & Pipeline

The model stays in character as GM while emitting valid JSON at the end of every response so the UI can update health, inventory, gold, and location live. Full conversation history sent on every API call — state management entirely through prompt design.

Research Relevance

  • Direct application of HCI principles — designing the interaction model so users stay immersed despite knowing they're talking to an LLM.
  • Getting consistent dual-mode output (narrative prose + structured JSON) required significant prompt iteration — a core prompt engineering challenge.
  • Demonstrates LLM-driven dynamic narrative, a key topic in AI for games research.
03 — dorm_escape_ai.unity

// Game AI · Agent Behaviour · Unity

Dorm Escape — AI Enemy System

github.com/hoorishahmad/dorm-escape · Unity · C# · Game AI

Dorm Escape · patrol · detection · chase state machine · Unity 3D

Problem & Objective

Design an NPC enemy AI that feels genuinely threatening — guards that patrol intelligently, detect the player through field-of-view checks, and escalate behaviour dynamically. Ship it as a complete playable stealth game.

Architecture & Pipeline

Finite state machine written from scratch in C#: patrol → alert → chase driven by FoV ray-casting and proximity triggers. Shipped a complete 3D game with stealth mechanics, collectibles, scene transitions, and animated UI.

Research & academic work

Where I want to go deeper.

I sit at the intersection of HCI, Game AI, and generative systems. My core question: how do we build AI that makes interactive experiences more intelligent, adaptive, and human-centred? That spans procedural content generation, NPC behaviour, LLM-driven narrative, and AR/VR interfaces. Pursuing a research-based MS or PhD abroad in the same space.

Procedural Content Generation via Reinforcement Learning (PCGRL)
Research Assistant · UET Peshawar · Supervisor: Engr. Abdullah Hamid · 2025 — ongoing
Investigating deep RL approaches to automated level and content generation for games. Working on training agents that learn to construct playable, well-structured game levels as a policy rather than through hand-crafted generation rules — directly in the PCGRL research tradition (Khalifa et al., 2020). Exploring how RL-trained generators can adapt output to player behaviour and skill level, connecting PCGRL to adaptive game design and HCI.
Object Recognition in AR Using ML Models
Final Year Project · UET Peshawar · 2025 — thesis submitted
Comparative study of four object detection architectures (YOLOv8, MobileNet, EfficientDet, SSD) deployed on-device inside a Unity AR scene via ONNX and Unity Sentis, with no inference server. Evaluated accuracy/latency tradeoffs under real-time AR constraints on a mid-range Android device.
